Banking Budget – Work in Progress

Creator / Full-Stack Developer (Personal Project)

Stack: React Native, Node.js (Express), AWS Lambda, PostgreSQL (with Prisma ORM), Supabase

Banking Budget (Temporal Name) is a mobile app that connects to users’ email accounts to automatically track and categorize financial transactions across multiple banks. The app offers budgeting tools, spending analysis, and notifications for better financial planning, all without the need for manual entry.

What I'm Building:

  • Backend developed with Node.js and Express to handle email parsing and transaction categorization.
  • Scheduled Jobs using AWS Lambda and cron jobs to sync transactions and update budgets at regular intervals.
  • Database transactions and user data are stored in a PostgreSQL database, with schema management and migrations powered by Prisma ORM.
  • Built using React Native to provide a seamless, cross-platform user interface.
  • Implementing notifications to alert users when they approach or exceed budget limits for specific categories or overall spending.

Why This Project?

I’m working on this app to help users in regions where banks don’t provide APIs or webhooks to automate the tracking and management of their finances. This app enables users to have all their banking and budgeting data in one place, automatically.
